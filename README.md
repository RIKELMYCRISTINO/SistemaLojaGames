# Sistema Loja de Games

## Descrição

O Sistema Loja de Games é um mini sistema desenvolvido em Java utilizando Programação Orientada a Objetos. O sistema permite o gerenciamento de jogos e clientes por meio de uma interface gráfica desenvolvida com Swing.

## Funcionalidades

- Cadastrar jogo
- Pesquisar jogo
- Remover jogo
- Atualizar preço do jogo
- Atualizar estoque do jogo
- Listar jogos
- Pesquisar jogos por categoria
- Pesquisar jogos por preço
- Cadastrar cliente
- Pesquisar cliente
- Remover cliente
- Listar clientes
- Salvar dados
- Recuperar dados

## Tecnologias utilizadas

- Java
- Swing
- Maven
- JUnit 5
- Collections (Map)
- Streams
- Serialização de Objetos

## Persistência

Os dados são gravados em arquivo utilizando serialização de objetos por meio da classe `GravadorDeDados`.
